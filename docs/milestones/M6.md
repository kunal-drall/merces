# M6 — Meteora support

**Built.** A Meteora Dynamic Bonding Curve port shaped after `@meteora-ag/dynamic-bonding-curve-sdk` 1.5.x (config
generation, pool state, swap quotes, token-badge check) and a DEX-aggregator port shaped after Jupiter Swap API V2,
both with mocks. E14 orchestration (Solana only): config generation through the port (Stage 1 owns the oracle-driven
generator), curve status with the public-price/no-transfer-limits notice, a buy builder that returns a USDG→USDC swap
route first when paying in USDG, graduation monitoring that cranks `graduateCurve`, and a `/admin/curves/monitor`
trigger. The simulator models the curve as a toy linear curve that graduates at the minimum raise (A-CURVE-1).

**Assumed.** The curve quotes in USDC; USDG enters through a swap (B8). Classic SPL USDC needs no token badge; Token-2022
quote mints with extensions do. Curve-mode units are modelled as 0-decimal units in the simulator.

**Open.** Which aggregator (Part J.7); Stage 1's real curve parameters and migration flow.
