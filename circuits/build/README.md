# circuits/build — DEVELOPMENT ARTEFACTS, NOT FOR PRODUCTION

Everything in this directory is produced by `circuits/scripts/build.sh` (`pnpm circuits:build` at the
repository root) from `circuits/src/report.circom`.

**The trusted setup here is a development ceremony and must never be used for a production deployment.**
Both the powers-of-tau and the phase-2 contribution are snarkjs *beacon* contributions seeded with the
public, fixed strings recorded in `MANIFEST.txt`. That makes the build byte-for-byte reproducible (so
the committed `report_final.zkey`, `verification_key.json`, the generated `evm/src/zk/Groth16Verifier.sol`
and `solana/programs/merces_protocol/src/zk/vk.rs` and the proofs embedded in `packages/vectors` all
agree), but it also means the toxic waste is public knowledge: anyone can forge proofs for this key.
Before any mainnet deployment the circuit must go through a real multi-party ceremony and the two
generated verifier files must be regenerated from that ceremony's key.

| File | Contents |
| --- | --- |
| `report.r1cs` | compiled constraint system |
| `report.wasm` | witness calculator (copy of `report_js/report.wasm`) |
| `report.sym` | signal names (gitignored) |
| `report_final.zkey` | Groth16 proving key after the dev phase-2 beacon |
| `verification_key.json` | snarkjs verification key (6 public inputs) |
| `MANIFEST.txt` | tool versions, constraint count, beacon strings and artefact hashes |
| `pot*_final.ptau` | prepared powers of tau (gitignored; regenerated by the build) |
